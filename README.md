# Aston-Cv-Portal
Full-stack web application built with PHP and MySQL for user authentication and dynamic CV management.

Aston CV Portal — Developer Directory & CV Management
A web portal I built for Aston students and developers to create, edit, and publicly display searchable professional CVs.

 What it does?
-User registration and secure login system using PHP session handling and password hashing.
-Searchable CV directory allowing users to filter developer profiles by name or programming language.
-Dynamic dashboard where logged-in users can update their profile, education, and portfolio links in real time.
-Detailed single-page CV views displaying full developer summaries and external links.

Tech stack
-PHP & MySQL (PDO)
-Bootstrap 5, HTML & CSS
-InfinityFree (Apache & Database Hosting)
